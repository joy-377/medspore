Screening Tests: Sensitivity, Specificity, PPV & NPV

Evaluating 2x2 diagnostic tables, prevalence impact, and SnNOut vs SpPIn rules...

Third Year (Part 1) · PSM

The Standard 2×2 Contingency Table:
Rows = Test Positive (T+) / Test Negative (T-). Columns = Disease Present (D+) / Disease Absent (D-).
• Cell A = True Positive (TP); Cell B = False Positive (FP)
• Cell C = False Negative (FN); Cell D = True Negative (TN)

Key Validity Indices:
• Sensitivity = TP / (TP + FN) × 100: Ability of a test to correctly identify those with the disease. High Sensitivity rules OUT disease when negative (SnNOut). Used for screening tests where missing a case carries high mortality (e.g., HIV, Blood donation screening).
• Specificity = TN / (TN + FP) × 100: Ability of a test to correctly identify those without the disease. High Specificity rules IN disease when positive (SpPIn). Used for confirmatory tests (e.g., Western blot, Biopsy).

Predictive Values & The Prevalence Effect:
• Positive Predictive Value (PPV) = TP / (TP + FP) × 100: Probability that a person with a positive test actually has the disease.
• Negative Predictive Value (NPV) = TN / (TN + FN) × 100: Probability that a person with a negative test is disease-free.
• Crucial Rule: When disease prevalence increases → PPV increases significantly, while NPV decreases. Sensitivity and Specificity remain completely unaffected by prevalence changes.
